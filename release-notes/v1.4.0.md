## FuckOff v1.4.0

### 新增清理方式
- 手动确认：只发通知，用户自行确认卸载
- Device Owner：通过系统 `PackageInstaller` 静默卸载
- Shizuku：通过本地 shell 执行 `pm uninstall --user 0`，不需要 Device Owner

### Shizuku 模式
- 在「自动处理 → 清理方式」中选择 Shizuku
- 会引导安装/启动 Shizuku、开启无线调试并申请权限
- Shizuku 未运行、未授权或命令失败时自动回退到手动通知
- 仅处理「跟随系统」的黑名单项；「仅手动」项始终需要确认
- 命令固定为 `pm uninstall --user 0 <包名>`，包名经过校验

### 兼容性
- 已在 HONOR BKQ-AN90（Android 16 / MagicOS 10.0.0.170）验证首页启动、清理方式选择、Shizuku 未安装时的配置引导
- 保留单项手动/跟随系统、导入强制手动、安全保护和 Apache-2.0 许可

### 安装
1. 下载 `FuckOff-v1.4.0.apk`。
2. 允许浏览器安装未知应用。
3. 覆盖安装，数据保留。

### 清理方式与风险
- 手动确认：无需特殊权限，但只能通知后由用户确认，通知可能被忽略。
- Device Owner：设备管理级权限，可静默卸载；配置通常需要无账户/恢复出厂，误删会直接丢失应用数据。
- Shizuku：shell 级权限，可静默卸载；依赖第三方 Shizuku 服务，配置需无线调试，服务被杀时会回退手动通知。
- 卸载没有回收站；请先备份并先用不重要的应用测试。
- 详见仓库 `CLEANUP_RISKS.md`。
